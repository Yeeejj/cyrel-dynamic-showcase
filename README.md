# Cyrel Edaño — Portfolio

Personal portfolio website.

**Live**: [cyrel-dynamic-showcase.vercel.app](https://cyrel-dynamic-showcase.vercel.app)

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- React Router

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
