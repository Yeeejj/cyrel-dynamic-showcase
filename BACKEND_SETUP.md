# Email Backend Service Setup Guide

Your portfolio now has a complete backend service that acts as a bridge between your contact form and your Gmail inbox. This is a secure, production-ready solution.

## Architecture

```
Contact Form (Frontend) 
    ↓ (sends name, email, message)
Express Backend Server (Node.js)
    ↓ (validates data)
Nodemailer
    ↓ (uses Gmail App Password)
Gmail SMTP Server
    ↓ (forwards to your inbox)
edano.cyreljane@gmail.com
```

## Prerequisites

- Node.js (already installed on your system)
- npm (package manager, comes with Node.js)
- Gmail account (edano.cyreljane@gmail.com)

## Step 1: Create Gmail App Password

This is required for Nodemailer to send emails through Gmail securely.

### Instructions:

1. Go to your Google Account: https://myaccount.google.com/

2. Click **"Security"** in the left sidebar

3. Under "How you sign in to Google", make sure **2-Step Verification** is ON
   - If not enabled, enable it first:
     - Click "2-Step Verification"
     - Follow the prompts to set it up

4. After 2-Step Verification is enabled, go to: https://myaccount.google.com/apppasswords

5. Select:
   - **App:** Mail
   - **Device:** Windows Computer (or your device type)

6. Google will generate a **16-character password**
   - Copy this password (it contains spaces - copy exactly as shown)

## Step 2: Set Up Backend Server

### 2.1 Install Backend Dependencies

Open PowerShell and navigate to the server directory:

```powershell
cd d:\codingsss\Portfolio\cyrel-dynamic-showcase\server
npm install
```

This installs:
- `express` - Web server framework
- `cors` - Enables cross-origin requests from frontend
- `nodemailer` - Email sending library
- `dotenv` - Loads environment variables

### 2.2 Create .env File

In the `server/` directory, create a new file named `.env` with this content:

```
GMAIL_USER=edano.cyreljane@gmail.com
GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx
PORT=5000
```

Replace `xxxx xxxx xxxx xxxx` with the 16-character App Password from Step 1.

**Example:**
```
GMAIL_USER=edano.cyreljane@gmail.com
GMAIL_APP_PASSWORD=abcd efgh ijkl mnop
PORT=5000
```

⚠️ **IMPORTANT:** Never commit this `.env` file to GitHub. It contains sensitive credentials.

## Troubleshooting

### Problem: "Cannot connect to email service"
- **Solution:** Make sure backend server is running (`npm run dev` in server folder)

### Problem: "Email service authentication failed"
- **Solution:** Check that Gmail App Password is correct in `.env` file
- The password must be exactly as generated by Google (16 characters with spaces)

### Problem: Backend shows "❌ Email transporter verification failed"
- **Possible causes:**
  - Wrong Gmail App Password
  - 2-Step Verification not enabled on Gmail account
  - Gmail account doesn't match `GMAIL_USER` in `.env`

### Problem: Email arrives but looks malformed
- **Solution:** Wait a moment and refresh - Nodemailer takes a few seconds

### Problem: Form submits but nothing happens
- **Solution:** 
  1. Open browser Developer Tools (F12)
  2. Check "Console" tab for error messages
  3. Check "Network" tab to see if request was sent

## API Reference

### Endpoint: POST /api/send-email

**Request:**
```json
{
  "name": "John Doe",
  "email": "john@example.com",
  "message": "Hello, I'm interested..."
}
```

**Success Response (200):**
```json
{
  "success": true,
  "message": "Email sent successfully! I will get back to you soon."
}
```

**Error Response (400/500):**
```json
{
  "success": false,
  "error": "Error description here"
}
```

## Deployment to Production

When deploying to production, you'll need to:

1. **Deploy Backend** to a service like:
   - Railway (recommended)
   - Render
   - Vercel (serverless)
   - Heroku

2. **Update Frontend** environment variable:
   - Create `.env.local` in project root:
   ```
   VITE_API_URL=https://your-production-backend-url.com
   ```

3. **Configure Email** on production server:
   - Set environment variables on hosting platform
   - Most platforms have a UI for this (Railway, Render, etc.)
